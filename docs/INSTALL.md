# Установка и первый запуск

Companion подходит для Majestic RP, других игр, работы и повседневных задач. Запускать игру для использования помощника необязательно.

## Что скачать

Открой [последний релиз](https://github.com/yashkarpsher/companion/releases/latest) и в разделе **Assets** выбери `Majestic-Companion-ВЕРСИЯ.zip`.

Распакуй весь архив. В одной папке должны находиться:

- `Majestic Companion.exe` — основная программа;
- `Companion Updater.exe` — помощник обновления, отдельно запускать его не нужно;
- `Microsoft.Web.WebView2.Core.dll`;
- `Microsoft.Web.WebView2.Wpf.dll`;
- `WebView2Loader.dll`.

Запусти **Majestic Companion.exe**. При первом открытии появится обучение. Его можно повторить через **«О программе» → «Пройти обучение»**.

## Требования

- Windows 10 или 11, 64-разрядная версия.
- .NET Framework 4.6.2 или новее.
- Microsoft Edge WebView2 Runtime для браузера: [официальная страница Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
- Для отображения поверх игры — режим **«Оконный» или «Окно без рамки» в настройках самой игры**. В эксклюзивном полноэкранном режиме окна Companion могут быть не видны.

## Обновление старой версии

Если установленная версия уже поддерживает обновления, используй предложение при запуске или кнопку **«Проверить обновление»** в настройках.

Для ручной установки полностью выйди из старой версии через дверцу или меню трея. Распакуй новую сборку и перенеси в неё свою папку `data`. Записи, фон и настройки хранятся в ней.

## Если не нажимаются кнопки

Возможно, включён режим пропуска мыши в игру. Нажми `Ctrl + Shift + G` или своё сочетание, если менял его в настройках.

## Если нет уведомления

После полного выхода программа не может показывать уведомления. Кнопка «−» сворачивает в трей и оставляет таймеры работать. Во время сна компьютера сигнал не прозвучит; о завершившемся таймере программа напомнит после пробуждения или следующего запуска.

## Файлы и контрольная сумма

Рядом с архивом в релизе опубликован файл `.zip.sha256`. Проверить скачанный ZIP можно в PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Majestic-Companion-0.13.5.zip'
```

Сравни значение с файлом контрольной суммы. Проверка подтверждает целостность скачивания.
