# 0.16.4

- В Дураке при уходе карт в бито появляется анимированная надпись «БИТО» по центру стола.
- В блэкджеке по центру анимированно появляются «ПЕРЕБОР», «ТЫ ВЫИГРАЛ», «ТЫ ПРОИГРАЛ» или «НИЧЬЯ».
- Кнопка «Раздать» и выбор ставки перенесены под карты игрока.
- Кнопка «Получить 1000 фишек» находится в раскрывающемся пункте «Запас фишек». Она добавляет фишки к текущему балансу и не обнуляет его; во время партии пополнение недоступно.

Windows 10/11 x64. Для браузера и Свина нужен Microsoft Edge WebView2 Runtime.
Для отображения поверх игры включите оконный режим или окно без рамки.

Распакуйте ZIP целиком. При ручном обновлении перенесите папку data при полностью закрытом Companion. Через встроенное автообновление данные сохраняются автоматически.
