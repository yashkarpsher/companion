# Companion 0.16.2

- Добавлен «Мистер Свин — Сундучок»: автономное окно, локальный прогресс, магазин за игровые монеты, без рекламы и реальных платежей.
- Свин первым по умолчанию; плитки мини-игр можно менять местами. Переставляются только выбранные две плитки, порядок сохраняется.
- Дурак и блэкджек: столы по центру, плавное появление карт, подъём карты в руке при наведении.
- Убрана информационная надпись в заголовке окна Свина.
- Ресурсы Свина встроены в EXE: игра доступна после автообновления со старых версий.

Windows 10/11 x64. Для браузера и Свина нужен Microsoft Edge WebView2 Runtime.
Для отображения поверх игры включите оконный режим или окно без рамки.

Распакуйте ZIP целиком. При ручном обновлении перенесите папку data при полностью закрытом Companion. Через встроенное автообновление данные сохраняются автоматически.
