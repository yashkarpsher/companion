## Companion 0.13.4 · Windows x64

Помощник для Majestic RP: таймеры, дела, заметки, виджеты поверх игры и браузер в одном приложении.

### Что умеет

- Напоминания через часы и минуты или на конкретную дату.
- Мини-режим, несколько отдельных виджетов и быстрые заметки.
- Браузер с регулировкой громкости и режимом без рамки.
- Своя палитра, фон, прозрачность и горячие клавиши.
- Финансы, калькулятор и две мини-игры.
- Обучение со скриншотами и ссылки на создателя.
- Проверка GitHub при запуске с вопросом «Хотите обновить?». Без сети проверка молча пропускается; ручная кнопка остаётся в настройках.

### Установка

Скачай **Majestic-Companion-0.13.4.zip** из Assets, распакуй целиком и запусти **Majestic Companion.exe**. Оставь DLL и **Companion Updater.exe** рядом. Автоматические архивы Source code — для исходников, а не готового приложения.

Нужны Windows 10/11 x64 и .NET Framework 4.6.2+. Для браузера нужен Microsoft Edge WebView2 Runtime.

При ручном обновлении полностью закрой прежнюю версию и перенеси папку **data** в новую папку программы. Таймеры и настройки сохранятся.
