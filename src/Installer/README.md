# Установщик Companion

Запусти `Companion-Setup.exe`, выбери папку и нажми «Установить».
Онлайн-установщик найдёт последнюю стабильную версию в GitHub Releases, скачает её и проверит архив перед установкой.
По умолчанию папка называется «Компаньон». Один и тот же установщик подходит для следующих версий программы.
По умолчанию программа устанавливается для текущего пользователя, без запроса прав администратора.
Можно создать ярлык на рабочем столе. Ярлык также появится в меню «Пуск».

Если раньше пользовался ZIP-версией, на странице переноса выбери её старую папку.
Папка `data` скопируется в новую установку. Оригинал останется на месте.
Если в новой папке уже есть свои данные, установщик не заменяет их другими.
При установке поверх той же папки перенос не нужен.
Перед установкой полностью закрой Companion через дверцу или меню трея.

Обновления через GitHub продолжают работать. Версия в ZIP остаётся доступной.
Удалить программу можно через «Установленные приложения» Windows.
Записи, фон, история браузера и настройки в папке `data` сохраняются даже после удаления программы.

Чтобы Companion показывался поверх игры, включи в игре оконный режим или окно без рамки.
Для браузера и некоторых мини-игр нужен Microsoft Edge WebView2 Runtime.
Для онлайн-установщика нужен интернет. Если GitHub временно недоступен или загрузка оборвалась, можно нажать «Установить» ещё раз. До успешной загрузки и проверки файлы программы и записи не меняются.
Для установки без интернета остаётся полный установщик `Companion-Setup-0.17.20.exe` с фиксированной версией.
Microsoft Edge WebView2 Runtime автоматически не скачивается. У установщиков пока нет цифровой подписи издателя.

## Сборка

Нужен [Inno Setup 6.7 или новее](https://jrsoftware.org/isdl.php).

Для онлайн-установщика запусти `build-installer.ps1 -Online -CompilerPath "путь к ISCC.exe"`.
Без `-Online` собирается полный установщик текущей версии.
Можно передать `-PayloadDirectory` с готовой сборкой и `-OutputDirectory` для результата.
Без готовой сборки сценарий соберёт Companion из соседних исходников.
Онлайн-установщик принимает стабильные релизы репозитория `yashkarpsher/companion` с архивом `Majestic-Companion-ВЕРСИЯ.zip` и SHA-256 от GitHub. Проверяются контрольная сумма, состав архива и версия внутри программы.
В полный установщик входят только явно перечисленные файлы программы. Личная папка `data` не упаковывается.

`-SmokeTest` создаёт отдельный тестовый установщик: другой идентификатор и мьютекс,
ярлык внутри тестовой папки, без регистрации в Windows. Для пользователей этот режим не используется.
Картинки мастера можно заново создать через `generate-art.ps1`.
